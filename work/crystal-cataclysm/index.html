Overview

Four corrupted caves, four bosses, one heart.

A crystal eruption has split the underground into glowing, unstable caves and mutated their creatures into bosses. The Crystal Cataclysm is a small-to-medium adventure map: a hub, four themed cave biomes and a final boss arena, in a dark fantasy crystal style.

Final boss

The Cataclysmic Core uses everything you've fought.

Once all four relics are claimed, the Crystal Heart Chamber opens. Each phase of the Core takes on a different biome, so the last fight tests what you learned in each one. The model swaps palettes between phases.

Blocks and progression

Loot that sets up the next cave.

Resources aren't just for score. Prism Fragments become the Prism Blade, which reflects projectiles. Refractor Bloom becomes flash bombs for blinding mobs in the dark. Crystal Chime fragments become sound traps that lure or repel mobs.

07

Thought process

  1. 01

    One loop, four flavours

    Every biome follows the same explore, fight, boss and relic loop, so players always know their goal while the setting keeps changing.

  2. 02

    Hazards with a counter

    Darkness drains you but light gear stops it. Floating shards crumble but gliders help. Every hazard has an answer you can craft.

  3. 03

    A finale that remixes

    The Core reuses all four biomes, so the last fight feels earned instead of random.

  4. 04

    Palette swaps for phases

    One boss model with phase palettes gives clear phase changes without four separate models.
