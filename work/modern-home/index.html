01

Overview

A luxury decor set, and a fix for a bug players kept hitting.

Modern Home is an Aurrora roleplay world: a neighbourhood of thirteen modern homes, and the studio's most-reviewed release. Internally the project is called Modern Millionaire. I'm the project owner for its update.

The update does two things. It adds 44 new pieces so players can furnish every room of a mansion. It also moves the garage doors, gate and kitchen appliances onto a script module, which fixes appliance parts coming loose after a world reload.

My role

Docs, spec and coordination.

  • Project docs. Wrote the overview, objectives, scope and acceptance criteria.
  • Block implementation spec. Listed every piece with its ID, placement rules, light level and behaviour, so devs could build it without guessing.

03

The collection

44 pieces, sorted by room.

The pack itself doesn't group anything. I sorted the pieces by room so the team could see the gaps and players could picture where each one goes. Pick a room to see what's in it.

Placement rules

  • Every piece is in the creative inventory, and faces the player when placed.
  • The Keypad Panel sticks to the wall it's placed on. Clothes Hangers have no collision.
  • Every new model works with the existing Rotate Model and Hammer tools, so nothing new to learn.
04

Interactive pieces

Things you can use without being told how.

The test was simple: can a player switch on a lamp, open the laptop and roll the chair without instructions? Bedside and Table Lamps toggle on and off. The Floor Lamp and Outdoor Lantern are always on. The Keypad Panel gives off a soft glow at light level 3.

05

The reload bug

Fixing appliances that fell apart.

The Fridge, Sink and Stove are built from several parts: doors, a drawer and burners. After a world reload, those parts could come loose from the appliance. The new script module re-attaches them when a player comes back near them.

06

Script module

One module for everything that moves.

The garage doors, the gate and the appliances now all run through one script module, built on @minecraft/server 2.10.0. Whether a door or gate is open is saved per world, so it's the same after a reload.

Old worlds keep working. In the script, the Driveway Gate is now called the Sliding Gate, but old commands and saved gate states still work. Owners who update the pack don't lose their builds.

07

Thought process

  1. 01

    Fix what players already own

    The reload bug affected existing owners, so the fix shipped in the same update as the new decor.

  2. 02

    Move to scripts

    Doors, gate and appliances now follow one set of rules in one place, instead of each piece working its own way.

  3. 03

    Don't break saved worlds

    Renaming the gate was worth doing only because old commands and saved states still work.

  4. 04

    No new tools to learn

    Every piece works with the existing Rotate Model and Hammer, and lights behave the way players expect.
